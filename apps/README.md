# Apps

Bu klasör monorepo içindeki çalıştırılabilir uygulamaları barındırır.

## Yapı

- `mobile/` → Native Flutter mobil uygulaması
- `../src/` → Mevcut .NET backend kaynak kodları

## Not

Bu geçişte mevcut backend klasör yapısı korunmuştur. İleride istenirse backend `apps/backend/` altına taşınabilir, ancak şimdilik risk azaltmak için mevcut çözüm yapısı bozulmamıştır.
